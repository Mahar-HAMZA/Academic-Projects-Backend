# Campus Emergency Assistance (CEA) - UI/UX Low-Fidelity Prototype

## 📌 Project Overview
Campus Emergency Assistance (CEA) is a mobile application prototype designed for college and university campuses. It provides students and faculty with single-tap emergency response services including Medical, Fire, Security, and General Help Requests.

## 📱 Core Features
1. **Splash & Authentication:** Simple onboarding with student login.
2. **Emergency Dashboard:** High-contrast tiles for instant emergency selection.
3. **Medical Emergency Hub:** Immediate access to First Aid Centers, On-Campus Doctors, and 24/7 Ambulance Hotline.
4. **Campus Navigation Map:** Live visual mapping with current location and nearest assistance pins.
5. **Direct SOS Helpline:** One-tap emergency call interface.
